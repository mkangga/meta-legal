Berlaku untuk aplikasi MKA Ads Manager, alat internal yang dipakai pemilik akun iklan untuk mengelola kampanye Meta melalui Marketing API.

Terakhir diperbarui: 21 November 2026

Pengelola dan cakupan

MKA Ads Manager adalah aplikasi internal yang dikelola oleh Muhammad Karim Anggara, pemilik MKA Store, dan digunakan hanya untuk mengelola akun iklan milik sendiri. Aplikasi ini bukan layanan publik: tidak ada pendaftaran pengguna, tidak ada akun pihak ketiga, dan tidak ada data milik pengiklan lain yang diakses.

Data yang diakses

Aplikasi mengakses data melalui Meta Marketing API setelah pemilik akun memberikan izin. Cakupan izin yang digunakan adalah ads_read dan ads_management, yang memberi akses pada:

  • Struktur akun iklan: kampanye, ad set, iklan, status, dan pengaturan penargetan.
  • Metrik performa: belanja iklan, tayangan, klik, CTR, CPM, CPA, dan metrik terkait.
  • Materi kreatif: gambar, video, teks utama, judul, dan tautan yang diunggah untuk iklan.
  • Informasi halaman Facebook yang terhubung sebagai identitas iklan.

Aplikasi tidak mengakses pesan pribadi, daftar teman, kiriman pengguna lain, maupun data dari akun iklan yang bukan milik pengelola.

Untuk apa data digunakan

Data digunakan untuk menjalankan fungsi pengelolaan iklan yang diminta pemilik akun, yaitu membuat dan mengubah struktur kampanye, mengunggah materi kreatif, membaca laporan performa, menjeda iklan yang tidak efisien, dan menyusun rekomendasi anggaran. Sebagian data dapat dikirim ke penyedia model bahasa untuk membantu menyusun teks iklan dan menganalisis performa. Data tidak dijual, tidak dipakai untuk penargetan pihak lain, dan tidak dipakai untuk melatih model AI umum.

Penyimpanan dan keamanan

Token akses disimpan pada server milik pengelola dengan izin berkas terbatas dan tidak dibagikan ke pihak lain. Data performa dan riwayat perubahan dapat disimpan sebagai berkas laporan di server tersebut. Komunikasi dengan layanan Meta menggunakan HTTPS. Akses ke server dibatasi hanya untuk pengelola.

Berapa lama data disimpan

Token akses disimpan selama aplikasi digunakan, atau sampai dicabut oleh pemilik akun. Laporan performa disimpan selama diperlukan untuk perbandingan dan evaluasi, dan dapat dihapus kapan saja atas permintaan pemilik akun.

Pilihan pemilik akun

Izin aplikasi dapat dicabut kapan saja melalui Pengaturan Bisnis Meta atau halaman aplikasi dan situs web di akun Facebook. Setelah dicabut, aplikasi tidak dapat mengakses data baru. Instruksi penghapusan data tersedia di halaman penghapusan data. Pertanyaan lain dapat dikirim ke mkalinode@gmail.com.

Kebijakan ini dapat diperbarui bila cakupan izin atau cara pemrosesan data berubah. Tanggal pembaruan ditampilkan di bagian atas halaman.
